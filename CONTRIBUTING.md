# Contributing to Nia Teams

Thanks for your interest in contributing to Nia Teams open-source projects!

## Workflow

1. Check existing issues or open a new issue before starting large architectural changes.
2. Fork the repository and create a topic branch from `main`.
3. Keep pull requests focused, include tests where applicable, and ensure CI passes.
4. Never commit credentials, tokens, internal endpoints, or private data.

By submitting a contribution, you agree that your contribution will be licensed under the project's `LICENSE`.
